Walmart — Passkey details

Official support for passkeys (WebAuthn) across web and mobile. Use platform authenticators or roaming authenticators to register and sign in securely without passwords.

Endpoints

POST /webauthn/register POST /webauthn/verify

How it works

  1. Client requests registration options from server.
  2. Client calls navigator.credentials.create() with the options.
  3. Client sends attestation to the server for verification and storage.
